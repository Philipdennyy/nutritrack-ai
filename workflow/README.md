# n8n Workflow

This directory contains the sanitized n8n workflow export for NutriTrack AI.

## Workflow Overview

The workflow connects Telegram, Google Gemini, and Google Sheets to provide AI-powered nutrition tracking.

## Setup Requirements

Before importing the workflow, configure your own:

* n8n instance
* Telegram bot and credentials
* Google Gemini API credentials
* Google Sheets document and credentials

Replace placeholder values with your own configuration.

## Security

This workflow export is intended for public sharing. Never commit API keys, bot tokens, passwords, private keys, or personal user data.
